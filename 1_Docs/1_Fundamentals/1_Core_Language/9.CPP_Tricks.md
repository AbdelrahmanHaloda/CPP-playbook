# Templates (Deep Dive Hub)

## Why this matters
Templates are one of the most powerful features in C++. They enable zero-cost abstractions, generic programming, and are the foundation of the STL.

Mastering templates is what separates intermediate C++ engineers from advanced ones.

---

## Core idea
Templates allow writing code that works with multiple types, with **compile-time code generation** (instantiation).

Unlike runtime polymorphism, templates achieve flexibility **without runtime overhead**.

---

## Mental model (IMPORTANT)
Think of templates as:

> "Code generator executed by the compiler"

Each usage creates a new version of the function/class.

---

## 1. Function templates

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

### Key points
- compiler deduces type
- multiple instantiations are generated

---

## 2. Class templates

```cpp
template <typename T>
class Box {
public:
    T value;
};
```

Used in STL (`std::vector<T>`, `std::map<K,V>`)

---

## 3. Template instantiation

```cpp
auto x = add(1, 2);   // generates add<int>
```

### Important
- only instantiated when used
- different types → different code

---

## 4. Template specialization

### Full specialization
```cpp
template<>
class Box<bool> {
    // specialized implementation
};
```

### Why needed
- customize behavior for specific types

---

## 5. Partial specialization (classes only)

```cpp
template<typename T>
class Box<T*> {
    // pointer specialization
};
```

---

## 6. Variadic templates

Handle variable number of arguments.

```cpp
template<typename... Args>
void print(Args... args);
```

Used heavily in:
- logging
- forwarding

---

## 7. Perfect forwarding

```cpp
template<typename T>
void wrapper(T&& arg) {
    func(std::forward<T>(arg));
}
```

### Why
Preserves value category (lvalue/rvalue)

---

## 8. SFINAE (C++11/14)

Substitution Failure Is Not An Error

Used to enable/disable templates.

```cpp
template<typename T>
auto foo(T t) -> decltype(t + 1) {
    return t + 1;
}
```

---

## 9. Concepts (C++20)

Cleaner alternative to SFINAE.

```cpp
template<typename T>
requires std::integral<T>
T add(T a, T b) {
    return a + b;
}
```

### Why important
- readable constraints
- better error messages

---

## 10. Compile-time polymorphism

Templates replace virtual functions in many cases.

### Comparison
| Feature | Templates | Virtual functions |
|--------|----------|------------------|
| Time   | Compile-time | Runtime |
| Overhead | None | vtable |
| Flexibility | Type-based | Inheritance-based |

---

## 11. Templates in STL (real-world)

- `std::vector<T>`
- `std::sort`
- `std::unique_ptr<T>`

STL is essentially a template library.

## Common mistakes
- overengineering with templates
- unreadable template code
- ignoring compile errors instead of understanding them
- mixing templates with bad design
